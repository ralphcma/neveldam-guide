NEVELDAM PLAYER GUIDE

A player-facing guide to the Neveldam investigation in Federation 2.

Website: https://ralphcma.github.io/neveldam-guide/

The main guide explains commands and the investigation without a worked
solution. Optional hints are on a separate page, with each hint initially
collapsed. Plain-text editions are also available.

Published files:
  index.html                       Main player guide
  Neveldam-Optional-Hints.html      Optional, progressively stronger hints
  Neveldam-Players-Guide.txt        Plain-text player guide
  Neveldam-Optional-Hints.txt       Plain-text hints (all levels visible)
  assets/notebook-menu-preview.png Spoiler-free notebook-menu illustration
  .nojekyll                        Serve these prebuilt files without Jekyll

Based on the Neveldam update dated 17 October 2026. This does not confirm
that a particular game server has installed that update.

Report issues to NeveldamPuzzle@gmail.com. Include your difficulty, room,
the command you sent and the response. Do not include account credentials
or post case answers publicly.

MAINTAINING THE SITE

GitHub Pages publishes from the main branch, repository root. Push updated
player-facing files to main to publish a revision. Preserve relative links,
including the optional-hints page's return link to index.html.

Only player-facing guide files belong here. Do not add game archives,
event/object/message source files, solver scripts, private state or logs.
